# Apple HIG source routing and web translation

These are selected Markdown snapshots from the user-provided Apple Human Interface Guidelines archive. Read the relevant originals in `hig/`; source identifiers appear in their headers. The source may be older than the current website. Check the live HIG when freshness is consequential. Images and native documentation links in the snapshots may not resolve locally.

| Need | Read | Transfer to websites | Do not transplant |
| --- | --- | --- | --- |
| Foundational tradeoffs | `hig/design-principles.md` | Purpose, agency, responsibility, familiarity, flexibility, simplicity, craft | An Apple visual identity |
| Hierarchy and responsive composition | `hig/layout.md`, `hig/typography.md`, `hig/color.md` | Visual hierarchy, readable type, adaptable regions, meaningful color | Native size classes, safe areas, platform points as web breakpoints |
| Inclusive interaction | `hig/accessibility.md` | Diverse vision, mobility, cognition and inputs; readable content | Apple APIs as substitutes for web semantics and testing |
| Brand and imagery direction | `hig/branding.md`, optionally `hig/color.md` | Distinctive brand within legible, consistent UI | System-app styling or branded Apple affiliation |
| Labels, buttons, and form language | `hig/writing.md`, `hig/buttons.md` | Plain action labels, useful guidance, consistent voice | Native control specifications without web context |
| Progressive details | `hig/disclosure-controls.md` | Prioritize common choices and clearly label reveals | Mac disclosure icon rules or hiding purchase-critical terms |
| Reveal and transition | `hig/motion.md` | Purposeful, brief, interruptible motion and alternatives | Native animation APIs or platform-specific effects |
| Consent and trust | `hig/privacy.md` | Transparency and user agency | Treating HIG as a replacement for applicable web law |

When citing guidance, name its local source file or original HIG topic. Distinguish the source's principle from this skill's additional web-marketing recommendation. Apple HIG does **not** prescribe a universal first-fold layout, sales funnel, conversion metric, or copy formula. Do not copy Apple's product artwork, UI chrome, or marketing voice merely to seem polished.
